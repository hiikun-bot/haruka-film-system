いちばん大事

他の人には、件数すら見えません

マイゴールは完全に個人用のページです。目標もタスクも、管理者を含めて本人以外は一切見られません（「目標が何件あるか」も見えません）。仕事の目標だけでなく、勉強・副業・私生活の予定を書いても大丈夫です。

画面の構成

ヘッダーのナビでは、目標意識を高めるためにホームの隣（2 番目）に「🎯 マイゴール」があります。全ロール共通です。

右上のボタン 📗 スプシを開く（連携後に出る） 📊 スプシ連携 ＋ 目標を追加 ＋ タスクを追加
上段 目標カード（進捗バー・カウントダウン） 💪 今週 N件完了 ／ 🔥 N日連続
タブ 📅 今週やること⏰ 期限順🌳 すべて

初めて開くと「マイゴールをはじめよう」の案内と「🎯 最初の目標を作る」ボタンだけが出ます。

初回セットアップ（「📊 スプシ連携」モーダルの手順どおり）

連携するのはあなたの Google ドライブにあるシートです。シートの持ち主はあなたなので、他の人からは見えません。

1sheets.new で新しいシートを作る
2シート右上の「共有」で、モーダルに表示されるシステム用メールアドレス（「コピー」ボタンあり）を「編集者」で追加（通知はオフで OK）
3シートの URL をコピーして「連携シートURL」に貼る
📤 エクスポート／📥 インポート
📤 スプシに出力 タスク一覧をシートの 1 枚目のタブ（タブ名「目標一覧」）に上書き
📥 取り込み 「🔍 差分をプレビュー」で確認 → 「📥 この内容で取り込む」 ID 列あり＝更新 / ID 列が空＝新規作成 / シートに無いタスクは消さない

一度出力すると URL がこの端末に記憶され、右上に「📗 スプシを開く」ボタンが出ます。シート上でまとめて編集 → 取り込み、という使い方ができます。

💬 困ったら…

🔒
本当に誰にも見えない？
はい。管理者を含め本人以外は一切見られず、件数も出ません。「担当者（自分のメモ）」で選んだ相手にも表示・通知されません
📗
「📗 スプシを開く」が出ない
連携シートの URL は端末ごとに記憶されます。「📊 スプシ連携」で URL を貼って一度出力すると出ます
⚠️
スプシに出力できない
シートの「共有」で、モーダルに表示されるシステム用メールアドレスを「編集者」で追加したか、URL が正しいかを確認してください
🗑
目標を消したらタスクはどうなる？
タスクは残ります（「関連する目標」が外れるだけ）。非表示にしたいだけなら、目標のステータスを「アーカイブ（非表示）」にしてください
📅
「今週やること」に何も出ない
期限が今週（月〜日）のタスクだけを表示します。期限なしのタスクは「🌳 すべて」か「⏰ 期限順」の末尾「期限なし」に出ます
