# Threads返信アシスタント

株式会社HARUKA FILM の個人向け試作 Chrome 拡張機能。GitHubでソース管理し、Threadsを読んでいるその場で「自然な返信案」を作ります。

## できること

- Threadsの画面で投稿テキストを選択し、右クリック → **この投稿の返信案を作る** でサイドパネルを表示。
- テキストが選択されていない場合も、右クリック位置の近くから投稿文の抽出を試みます（画面構成が変わると失敗する可能性あり）。
- 自動抽出された文章を修正・確認できます。
- 「会話を続ける」「相手を自然に褒める」「共感を伝える」「行動を称える」「気持ちよく締める」から選択。
- OpenAI APIで自然な日本語の返信案を3件生成し、編集してワンクリックコピー。
- **自動投稿はしません**。投稿操作はThreads上でご自身が行います。

## インストール（Mac / Windows の Chrome）

1. このフォルダ（`tools/threads-reply-helper`）を手元のPCに用意します。
2. Chromeで `chrome://extensions/` を開き、「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」から、このフォルダを指定します。
4. Threadsをブラウザーで開きます（`threads.com` または `threads.net`）。
5. 右クリックし「この投稿の返信案を作る」を選びます。
6. 「APIキー設定・料金について」を開き、ご自身の OpenAI APIキーを入力・設定します。
7. 返信候補を生成し、確認してコピーした後、Threadsに貼り付けて送信します。

初回は、投稿の本文をドラッグで選択してから右クリックする方法が確実です。投稿周辺の自動抽出は画面仕様依存のため、間違った文章が入っていないか毎回確認してください。

## APIキーとデータの扱い

- OpenAI APIはChatGPTのサブスクリプションとは**別課金**です。モデルは `gpt-6-luna`（変更する場合は `panel.js` を編集）。
- キーはGitHubにもThreadsにも送信されません。拡張機能からOpenAI APIへ直接アクセスします。
- デフォルトは `chrome.storage.session` に一時保持し、Chromeのセッション終了時に消えます。
- 「次回以降もこの端末に保存」を選ぶと、`chrome.storage.local` に保存されます。Chromeのlocal保存は暗号化された秘密情報保管庫ではありません。共有PCでの永続保存は避けてください。
- 返信生成時、入力欄の投稿本文と指示内容がOpenAI APIへ送信されます。
- APIには `store: false` を指定しています。
- 他のChrome拡張機能や端末のマルウェアからの漏えいを完全に防げる保証はありません。本格運用では、サーバー側でキー管理する構成への移行を推奨します。
- APIキーはGitHubのファイルへ一切書かないでください。

## 制約

- Chrome 116 以降を想定したManifest V3拡張機能です。
- ThreadsのDOM構造が変更されると「投稿を自動取得」する処理は動かなくなる可能性があります。テキスト選択、または貼り付けは引き続き利用できます。
- 自動投稿／大量の自動返信／無人での巡回は実装していません。
- この試作は実ユーザーのThreadsログインやOpenAI APIキーを使った実機テストをまだ行っていません。

## 将来の拡張

公式Threads APIによる取得・返信にはMetaアプリ登録、OAuth、必要な権限が必要です。別フェーズとして審査・運用ポリシーを確認して進めてください。
